# Pagewatch AI v0.1

This is the frozen target behavior for v0.1, not a description of the current implementation.

## Goal

Monitor configured web pages and notify the user about meaningful changes.

## Core flow

```text
fetch -> extract -> normalize -> compare
      -> classify changed content -> notify -> commit state
```

## Scope

- Multiple configured watches for HTTP/HTML pages
- CSS selector based extraction
- Persisted local baseline and diff
- LLM relevance classification
- Email notifications
- CLI, logs, and meaningful exit codes
- systemd deployment
- Tests and CI

## Non-goals

- Browser automation or a web UI
- Database, Docker, plugins, or queues/workers
- Accounts or users
- Notification integrations other than email

## Key invariants

- A failed fetch must never replace a valid baseline.
- Failed classification must never lose a detected change.
- Failed notification must never mark a relevant change as handled.
- The first run establishes a baseline and does not notify.
